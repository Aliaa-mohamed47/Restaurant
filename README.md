# 🍴 Restaurant – Responsive Bootstrap Website

**Restaurant** is a fully responsive website built using **HTML**, **CSS**, and **Bootstrap 5**. It features a clean and modern layout with smooth navigation across sections like Home, About, Menu, and Contact — ideal for showcasing a food business or practicing Bootstrap design.

## 🔗 Live Demo

👉 [Click here to view the website](https://aliaa-mohamed47.github.io/Restaurant/)

---


## 📁 Features

- ✅ Built with **Bootstrap 5**  
- ✅ Fully responsive on all screen sizes  
- ✅ Clean and simple layout  
- ✅ Smooth scrolling and navigation  
- ✅ Fast and lightweight
